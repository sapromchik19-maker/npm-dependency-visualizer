
# Визуализатор зависимостей npm

Практическая работа №2 по дисциплине
«Конфигурационное управление».

Вариант №4.

## Описание

Консольное приложение на Python для анализа
и визуализации зависимостей npm-пакетов.

Проект разрабатывается поэтапно.

## Параметры

- `--package` — имя npm-пакета.
- `--repository` — URL репозитория или путь к файлу.
- `--version` — версия пакета.
- `--output` — имя выходного SVG-файла.
- `--test-mode` — режим тестового репозитория.
- `--ascii` — режим вывода ASCII-дерева.

## Запуск

```powershell
python -m src.main --package express --repository https://registry.npmjs.org --version 4.18.2 --output graph.svg --ascii
```

## Тестирование

```powershell
python -m unittest discover -s tests -v
```

## Этап 1

Реализованы обработка параметров командной строки,
их проверка и вывод на экран.

Получение зависимостей и построение графа
будут добавлены на следующих этапах.
